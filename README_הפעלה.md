# אפליקציית Streamlit לסקירת טיפול בצנובמט

## מה מכילה החבילה

- `xcopri_app.py` — קובץ האפליקציה הראשי.
- `clinical_content.py` — תוכן האינטראקציות התרופתיות והאזהרות.
- `references_data.py` — 23 מקורות לפי סדר המאמר הסופי: 21 מאמרים ושני מסמכים רגולטוריים.
- `requirements.txt` — תלויות ההפעלה.
- `fonts/` — גופני DejaVu Sans והרישיון שלהם, להצגת סימנים רפואיים ושמות מקורות בקובצי PDF.
- `מקורות_בדיקת_DOI.md` ו־`reference_audit.json` — פירוט הבדיקה והנתונים הביבליוגרפיים שאומתו.

שמרו את שלושת קובצי ה־Python ואת תיקיית `fonts` באותה תיקייה: הקובץ הראשי מייבא את שני מודולי התוכן. אין להפעיל את הקובץ הראשי לבדו. אם הגופנים אינם זמינים גם במערכת, ייצוא PDF ייעצר עם הודעת שגיאה במקום להציג סימנים שעלולים להיות שגויים.

## הפעלה במחשב

יש להתקין Python וסביבת הרצה. בחלון טרמינל פתחו את התיקייה שבה חולצה החבילה והריצו:

```bash
python -m venv .venv
```

ב־Windows הפעילו את הסביבה באמצעות `.venv\Scripts\activate`; ב־macOS או Linux הריצו:

```bash
source .venv/bin/activate
```

לאחר מכן:

```bash
python -m pip install -r requirements.txt
python -m streamlit run xcopri_app.py
```

Streamlit יציג כתובת לפתיחת האפליקציה בדפדפן. כדי להפסיק את השרת, לחצו `Ctrl+C` בטרמינל.

## עדכון אתר Streamlit קיים

החבילה **לא נפרסה** באתר הקיים. כדי לעדכן אותו יש להחליף במאגר או בסביבת הפריסה את `xcopri_app.py` ואת `requirements.txt`, ולהוסיף באותה תיקייה את `clinical_content.py`, את `references_data.py` ואת תיקיית `fonts` עם כל תוכנה. אם האתר משתמש בשם קובץ ראשי שונה, יש לעדכן גם את פקודת ההפעלה או את נתיב ה־main file בהגדרות הפריסה. לאחר הפריסה נדרש לבדוק את הגרסה המותקנת, את הקישורים ואת כל תרחישי השימוש הרלוונטיים באותה סביבה.

## מה השתנה ביחס ללוגיקה שתוארה במאמר

גרסה זו היא אב־טיפוס שמרני לסקירת מידע, ולא תוכנית מרשם. היא מציגה דוגמת טיטרציה כללית של צנובמט למבוגרים עם תפקוד כבד וכליות תקין שאושר, ללא התוויות־הנגד הנבחרות, וכאשר נשקל יעד של 200 מ״ג ליום. מצבים אחרים אינם נחשבים בהכרח אסורים לטיפול, אבל נמצאים מחוץ למסלול החישוב המצומצם של הכלי.

**אין בגרסה זו הפחתה או העלאה אוטומטית של תרופות נלוות**, אין חישוב אוטומטי של taper לפי רמות דם ואין פיצול אוטומטי לבוקר וערב. אפשר להזין ערכי מינון היפותטיים ידנית לצורך סקירה; הם מוצגים רק לאחר אישור מפורש של סקירת הערכים. הדוגמה מהמאמר מוצגת בנפרד כחומר לימודי קבוע, לא כתוכנית למטופל, והעלאות הלמוטריג׳ין בה הן הצעות של המחברים שאינן מאומתות או המלצת קונצנזוס. לפיכך, המימוש הנוכחי שמרני יותר מהתיאור במאמר של יצירת תוכניות אישיות אוטומטיות; יש ליישב הבדל זה לפני פרסום או שימוש.

המלצת פאנל Delphi לגבי הפחתה יזומה או הפסקה של חוסמי תעלות נתרן מתייחסת למצב שבו כבר היו **שני חוסמים או יותר** בטיפול לפני הוספת צנובמט; אין היא מחייבת הפסקת תרופה מסוימת או את הקצב שבדוגמה. הכלי גם מעלה סקירה נפרדת כאשר lacosamide הוא 400 מ״ג ליום ומעלה. הסף מעל 20 מ״ג ליום ל־clobazam הוא כלל תפעולי של המחברים, לא סף בטיחות, וגם במינונים נמוכים יותר ייתכן צורך בשינוי לאחר סקירה רפואית.

Everolimus כלול כדוגמה לתרופה שאינה ASM, אך האפליקציה אינה מספקת סקירה מקיפה של אינטראקציות עם תרופות אחרות שאינן ASM. קלט רמת everolimus מושבת עקב פער ביחידות בממשק המקורי; יש לבצע ניטור ריכוזים לפי ההתוויות וההנחיות הקליניות מחוץ לכלי.

## הפניות

המקורות מוצגים לפי מספור המאמר. מזהי ה־DOI של 21 המאמרים הושוו לרשומות ביבליוגרפיות וההפניות ב־doi.org נבדקו. FDA ו־EMA הם מסמכים רגולטוריים ולא DOI. המקור Krauss 2025, שלא הופיע ברשימת המאמר הסופי, הוסר ולא יוחס לפריט אחר. מידע המוצר האירופי בקישור הוא מסמך מתעדכן; יש לבדוק את הגרסה התקפה במועד השימוש.

## בטיחות ופרטיות

הבדיקות הטכניות אינן תיקוף קליני, בדיקת אבטחת מידע, אישור רגולטורי או אישור כמכשיר רפואי. נדרשת סקירה עצמאית של מומחה לאפילפסיה ושל רוקח קליני או פרמקולוג קליני, ובדיקה מוסדית ורגולטורית מתאימה, לפני שימוש בקבלת החלטות למטופלים. יש לאמת את עלוני התרופות התקפים בישראל, יחידות, חוזקי הטבליות והאפשרות לחצות כל תכשיר.

אין להזין פרטים מזהים ללא בדיקת סביבת השרת והרשאותיה ואישור מוסדי מתאים. סביבת Streamlit עלולה להיות מרוחקת; זיכרון ההפעלה, רישומי השרת, הגישה לקבצים, ההצפנה ומשך השמירה תלויים באופן הפריסה. קובצי CSV ו־PDF מיוצאים עשויים להכיל מידע רגיש ויש לשמור אותם בהתאם למדיניות המוסד.

## בדיקות תוכנה אופציונליות

קובץ `test_integration.py` כולל בדיקות אוטומטיות עם נתוני דמה לתרחישי הממשק, האינטראקציות, ההפניות והייצוא. כדי להריצן יש להתקין בנוסף `pytest` ואת כלי המערכת `pdftotext` מתוך Poppler, ואז להריץ מאותה תיקייה:

```bash
python -m pip install pytest
python -m pytest -q test_integration.py
```

תלות זו מיועדת לבדיקות בלבד ואינה נדרשת להפעלה רגילה של האפליקציה. בדיקות התוכנה אינן מחליפות בדיקה ותיקוף של התוכן הקליני.
