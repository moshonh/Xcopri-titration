# אפליקציית Streamlit לסקירת טיפול בצנובמט

## הפעלה

יש להשתמש ב־Python 3.11 ומעלה. חלצו את החבילה ושמרו את כל קובצי ה־Python, את `requirements.txt` ואת תיקיית `fonts` באותה תיקייה. פתחו טרמינל בתיקייה זו והריצו:

```bash
python -m venv .venv
```

ב־Windows הפעילו את הסביבה באמצעות `.venv\Scripts\activate`; ב־macOS או Linux הריצו `source .venv/bin/activate`. לאחר מכן הריצו:

```bash
python -m pip install -r requirements.txt
python -m streamlit run xcopri_app.py
```

Streamlit יציג כתובת לפתיחת האפליקציה בדפדפן. עצרו את השרת בטרמינל באמצעות `Ctrl+C`. גופני DejaVu שבתיקיית `fonts`, כולל קובץ הרישיון, נדרשים להצגת סימנים רפואיים ב־PDF במערכות שבהן אין גופני מערכת מתאימים.

## עדכון אתר קיים

הגרסה בחבילה לא נפרסה לאתר הקיים. כדי לעדכן אתר Streamlit יש להעלות את קובצי ה־Python, את `requirements.txt` ואת תיקיית `fonts` בשלמותה לאותה תיקייה במאגר האתר. אם שם הקובץ הראשי באתר שונה מ־`xcopri_app.py`, יש לעדכן גם את נתיב קובץ ההפעלה בהגדרות האתר. לאחר פריסה יש לבדוק את הגרסה, תרחישי ההפעלה והייצוא באותה סביבת פריסה.

## כללי המינון והשליטה של הרופא

לוח צנובמט הכללי מוגבל בתחום החישוב של הגרסה למבוגרים עם תפקוד כליות וכבד תקין שאושרו, ללא familial short-QT או רגישות־יתר, ועבור יעד נשקל של 200 מ״ג ליום. כאשר נבחרת אפילפסיה כללית מופיעה אזהרה שהיא אינה ההתווייה המאושרת בעלונים האמריקאי והאירופי שהוזכרו; האזהרה אינה מציגה שימוש מחוץ להתוויה כהתוויית־נגד פורמלית.

התאמות התרופות הנלוות הן **הצעות שהוגדרו לפי ניסיון המחברים**, לא פרוטוקול מתוקף או הוראה של FDA, EMA או פאנל Delphi. שיעורי השינוי מחושבים מול מינון הבסיס היומי, ולא כשינויים מצטברים מתקופה קודמת. הרופא רשאי להחליף את הערכים בהצעה ידנית ולבדוק אותם לכל תקופה. יש לבדוק מצבו של המטופל, יעילות, תופעות לוואי, תרופות אחרות, ריכוזים כשנדרשים, ועלונים תקפים; כל החלטה היא באחריות הרופא המטפל.

בלשונית תוכנית הטיטרציה אפשר לבחור במסלול הצעות המחברים או במסלול ערכים שהרופא מזין. תצוגת הטיוטה זמינה לפני אישור; הפקת PDF או CSV דורשת אישור מפורש של סקירת התוכנית הנוכחית. שינוי בנתוני המטופל, בתרופות או בערכי התוכנית מבטל את האישור ומחייב סקירה מחודשת.

- **Clobazam / Frisium:** אם מינון הבסיס גבוה מ־20 מ״ג ליום, הכלל של המחברים מציע בתקופות הדו־שבועיות בהתאמה 100%, 100%, 75%, 75%, 50%, 50% ממינון הבסיס. ב־20 מ״ג ליום ומטה הוא אינו מציע הפחתה אוטומטית. סף זה אינו סף בטיחות; גם במינונים נמוכים עשויה להידרש הפחתה לאחר הערכה קלינית.
- **Lamotrigine / Lamictal:** הכלל של המחברים מציע 100%, 100%, 115%, 115%, 130%, 130% ממינון הבסיס, אלא אם נבחר מסלול ירידה לתרופה או שהרופא משנה זאת. זו אינה המלצת קונצנזוס לעלייה גורפת. העלון האמריקאי מתייחס להעלאה לפי הצורך; יש להביא בחשבון גם שינוי בתרופות משרות, שעלול להשפיע על ריכוזי למוטריג׳ין.
- **הפחתת תרופה נבחרת:** עבור תרופות שלהן היה כלל ירידה מוגדר בגרסה המקורית, אפשר להציג את רצף ברירת המחדל של המחברים או להחליפו בערכים שמזין הרופא. עבור תרופה שאין לה כלל ירידה מוגדר, אין לאפליקציה לנחש קצב ויש להזין ערכים ידנית. בחירת למוטריג׳ין להפחתה גוברת על כלל העלאת למוטריג׳ין; אותה תרופה אינה מקבלת בו־זמנית הצעת הפחתה והעלאה.

אין להסיק מערך חסר שמינון התרופה הוא אפס. ערכי הטבלה הם מינונים יומיים מחושבים לצורך סקירה: הם אינם מעוגלים אוטומטית לחוזקי טבליות, אינם הוראה לחלוקת טבלייה, ואינם מחולקים אוטומטית למנות בוקר וערב. יש לוודא התאמה לפורמולציה המקומית עם רוקח. רמות תרופות משמשות לסקירה בלבד, ואינן מאיצות הורדת מינון באופן אוטומטי.

## הפניות

האפליקציה כוללת 23 מקורות, מתוכם 21 מאמרים עם DOI מאומת ושני מסמכים רגולטוריים שאינם DOI. FDA ו־EMA מפנים למסמכים שנבדקו; מידע המוצר האירופי עשוי להשתנות ויש לבדוק את הגרסה התקפה. המקורות וקישוריהם אינם מחליפים עיון בעלונים ובהנחיות המקומיות.

## בטיחות ופרטיות

הבדיקות הטכניות אינן תיקוף קליני, בדיקת אבטחת מידע, אישור רגולטורי או קביעה של מעמד האפליקציה כמכשיר רפואי. נדרשת סקירה עצמאית של מומחה לאפילפסיה ושל רוקח קליני או פרמקולוג קליני, ובדיקה מוסדית ורגולטורית מתאימה, לפני שימוש בקבלת החלטות למטופלים.

הנוסח המקורי של הצהרת הפתיחה נשמר ללא שינוי, אך משפטיו על הפעלה מקומית ושמירת מידע תקפים רק לפריסה מקומית שנבדקה בפועל. אתר Streamlit מרוחק עשוי להעביר ולעבד נתונים בשרת. אין להזין פרטים מזהים ללא בדיקת סביבת ההפעלה וההרשאות ואישור מוסדי מתאים. קובצי הייצוא עשויים להכיל מידע רגיש.

## בדיקות תוכנה אופציונליות

קובצי `test_*.py` וסנפשוט הדיסקליימר כוללים בדיקות תוכנה עם נתונים סינתטיים. כדי להריץ אותם יש להתקין בנוסף את `pytest` ואת כלי `pdftotext` של Poppler, ואז להריץ באותה תיקייה:

```bash
python -m pip install pytest
python -m pytest -q test_interface_requirements.py test_titration_rules.py test_plan_flow.py
```

כלים אלה נחוצים רק לבדיקות, ולא להפעלה רגילה. בדיקות תוכנה אינן מחליפות תיקוף קליני.
